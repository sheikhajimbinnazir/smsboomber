# SMS Security Testing & Load-Check Tool (Bangladesh)

> **Strictly for Educational & Authorized Security Testing Only**

এই টুলটি মূলত শিক্ষামূলক উদ্দেশ্যে, সাইবার সিকিউরিটি রিসার্চ এবং **নিজের বা অনুমতিপ্রাপ্ত সিস্টেমে** OTP/SMS ডেলিভারি আচরণ পরীক্ষা করার জন্য তৈরি করা হয়েছে।

⚠️ **এটি কোনোভাবেই স্প্যাম, হ্যারাসমেন্ট বা অবৈধ আক্রমণ করার জন্য ব্যবহার করা যাবে না।**

---

## ✨ Features / বৈশিষ্ট্য

- 🔐 **Password Protection** – টুল রান করার আগে পাসওয়ার্ড দিতে হয়।
- 📜 **Banner & Disclaimer** – টুল ব্যবহারের আগে নৈতিক ও আইনগত সতর্কতা দেখায়।
- 🇧🇩 **Bangladesh-only Number Format** – শুধুমাত্র `01*********` (১১ ডিজিট) ফরম্যাটের নম্বর গ্রহণ করে।
- 🔁 **Multiple API Calls** – বিভিন্ন সার্ভিসে OTP/SMS রিকোয়েস্ট পাঠিয়ে লোড/বিহেভিয়ার পর্যবেক্ষণ (স্ক্রিপ্টে যেভাবে কনফিগার করা আছে)।
- 🧵 **Multithreading** – একাধিক রিকোয়েস্ট একসাথে পাঠানোর জন্য থ্রেড ব্যবহার।
- 📈 **Request Counter** – সফল রিকোয়েস্টের সংখ্যা দেখায়।

> ⚠️ প্র্যাকটিক্যালি ব্যবহার করার আগে লুপ, থ্রেড সংখ্যা ইত্যাদি এমনভাবে পরিবর্তন করা জরুরি যেন **অতিরিক্ত লোড বা স্প্যাম না হয়**।

## 🧩 How it Works (High-Level) / কিভাবে কাজ করে (সংক্ষেপে)

> এখানে শুধুমাত্র হাই-লেভেল ব্যাখ্যা দেওয়া হচ্ছে, যাতে তুমি কোডটা বোঝো—অন্যকে আক্রমণ করার জন্য নয়।

- `banner()` → টার্মিনাল ক্লিয়ার করে বড় ডিসক্লেইমার/ব্যানার দেখায়।
- `password_prompt()` → সঠিক পাসওয়ার্ড ছাড়া টুল ব্যবহার করা যায় না।
- `get_target()` → ইউজারের কাছ থেকে `01*********` ফরম্যাটে নম্বর নেয় এবং সাথে `8801*********` ফরম্যাটও বানায়।
- `fast_apis()` → কয়েকটি API-তে দ্রুত GET রিকোয়েস্ট পাঠায়।
- `normal_apis()` → কিছু API-তে POST রিকোয়েস্ট পাঠায়।
- `start_bombing()` → লুপের মাধ্যমে বারবার থ্রেড চালিয়ে `fast_apis` এবং `normal_apis` রান করায়, আর প্রতিবার সফল হলে কাউন্টার আপডেট করে।

> ✅ **নিরাপদ ব্যবহারের জন্য**: এই লুপটা বাস্তবে ব্যবহার করার আগে এমনভাবে পরিবর্তন করা সুপারিশ করা হয় যেন নির্দিষ্ট সংখ্যক রিকোয়েস্টের পর থেমে যায় এবং শুধু নিজের/অনুমতিপ্রাপ্ত নম্বরে পরীক্ষা করা হয়।
